## 一、视觉识别算法原理

### 1.1 经典CV方法：矩形检测

**为什么用矩形检测而不是圆形/HOG/模板匹配？**

电赛E题的靶标是**黑白矩形边框**，具有明确的几何特征：
- 闭合四边形，四个角点清晰
- 内部白色/外部背景可区分
- 对边平行、邻边垂直
- 面积在画面中占比可预测

这些特征使得经典CV方法比YOLO等神经网络更简单、更快、不需训练数据。

**通用算法流程（与硬件平台无关）**：

```
                        ┌──────────┐
                        │ 摄像头帧  │
                        └────┬─────┘
                             ▼
                    ┌───────────────┐
                    │  预处理        │
                    │ (灰度/HSV掩膜) │
                    └───────┬───────┘
                            ▼
                    ┌───────────────┐
                    │  边缘检测      │
                    │ (Canny/Sobel) │
                    └───────┬───────┘
                            ▼
                    ┌───────────────┐
                    │  形态学处理    │
                    │  (膨胀/闭运算) │
                    └───────┬───────┘
                            ▼
                    ┌───────────────┐
                    │  轮廓查找      │
                    │ findContours  │
                    └───────┬───────┘
                            ▼
                    ┌───────────────┐
                    │  多边形逼近    │
                    │ approxPolyDP  │
                    └───────┬───────┘
                            ▼
                    ┌───────────────┐
                    │  四边形筛选    │
                    │  (多维度评分)  │
                    └───────┬───────┘
                            ▼
                    ┌───────────────┐
                    │  对角交点计算  │
                    │  → 靶心坐标    │
                    └───────────────┘
```

**各步骤参数调优指南**：

| 步骤 | 参数 | 效果 | 调参方向 |
|------|------|------|---------|
| HSV掩膜 | V通道上限 | 过滤背景 | 环境暗→降低上限(60-80)；环境亮→提高(90-120) |
| Canny | low_threshold | 边缘敏感度 | 弱边缘→降低(30-50)；噪点多→提高(60-80) |
| Canny | high_threshold | 强边缘阈值 | 一般为low的2-3倍 |
| 膨胀 | kernel大小 | 连接断裂边缘 | 矩形框完整→缩小(3×3)；断裂多→增大(7×7) |
| 膨胀 | iterations | 膨胀次数 | 同上，一次调整一步 |
| approxPolyDP | epsilon比例 | 逼近精度 | 矩形变形大→增大(0.03-0.05)；矩形标准→减小(0.01-0.02) |
| 面积筛选 | min_area | 过滤噪点 | 画面上矩形大→提高；矩形小/远→降低 |

### 1.2 YOLO目标检测方法

当矩形特征不明显（变形、遮挡、光照极端），或需要检测**非矩形目标**时，使用YOLOv8神经网络。

**与经典CV的互补关系**：

| 维度 | 经典CV矩形检测 | YOLOv8 |
|------|:-----------:|:------:|
| 需要训练数据 | 否 | 是（需要标注） |
| 对矩形形变的鲁棒性 | 中（依赖角点清晰） | 高 |
| 对遮挡的鲁棒性 | 低 | 中高 |
| 对光照变化的鲁棒性 | 低 | 高（增强后） |
| 检测非矩形目标 | 不支持 | 支持 |
| 计算资源需求 | 低 | 中高（需NPU加速） |
| 输出信息 | 4角点+中心 | 包围框+类别+置信度 |
| 部署复杂度 | 低 | 中（需模型转换） |

### 1.3 双模式切换

```
        config.json                 main.py 入口
     detection.mode = ?          if MODE == "yolo":
             │                       run_yolo()
             ▼                   else:
   ┌──────────────────┐              run_cv()
   │ cv   → 矩形检测   │
   │ yolo → KPU检测    │        两模式统一输出:
   └──────────────────┘        物体中心 → (dx,dy) 偏差 → servo_send
```

- CV 模式：矩形四边形中心 `quad_center(box)` 为追踪点，精度高、无帧率损失
- YOLO 模式：识别框中心 `(x+w//2, y+h//2)` 为追踪点，鲁棒性好、支持任意类别
- 实际实现见 [k230/main.py](file:///c:/Users/12553/Desktop/视觉/复刻/k230/main.py) 第九节「入口 — 模式切换」

### 2.1 双轴位置控制结构

```
         x_target=0                                    X轴输出
画面中心 ──────→ [Σ] ──→ [X轴PID] ──→ 执行机构 ──→ 云台偏转
                  ↑                                      │
                  │          偏差数据                      │
              x_site  ←──────────────←  视觉检测的X偏差 ────┘
                  
         y_target=0                                    Y轴输出
标定中心 ──────→ [Σ] ──→ [Y轴PID] ──→ 执行机构 ──→ 云台俯仰
                  ↑
              y_site  ←──────────────←  视觉检测的Y偏差
```

**PID参数物理含义**：

| 参数 | 作用 | 典型范围 | 过大导致 | 过小导致 |
|------|------|---------|---------|---------|
| Kp | 比例增益——响应速度 | 0.05~1.0 | 超调振荡 | 响应慢、静态误差大 |
| Ki | 积分增益——消除稳态误差 | 0.0001~0.01 | 积分饱和、过冲 | 有静态误差时无法对准 |
| Kd | 微分增益——抑制超调 | 0~0.1 | 对噪声敏感、抖动 | 超调无法抑制 |

**实测调参经验**：

```
精细对准模式: Kp=0.084, Ki=0.00047, Kd=0        ← 稳定但响应慢
快速跟踪模式: Kp=0.8,   Ki=0,       Kd=0        ← 响应快但可能有超调
Y轴系数取反:  y轴Kp = -x轴Kp                    ← 因为Y轴执行机构安装方向相反
```

### 2.2 状态机设计（多模式切换）

参考原方案 `mode` + `keycnt` 组合状态机：

```
mode=0: IDLE        — 待机，执行机构不使能
mode=1: TRACK       — PID追踪，keycnt=3或4切换子模式
mode=2: SCAN_RIGHT  — 单向扫描，检测到目标后切回TRACK
mode=4: SCAN_LEFT   — 反向扫描
mode=5: RESET       — 复位到TRACK
```

> 丢失目标时先短暂保持（`lost_hold`），确认丢失后再进入扫描/搜索，避免误切换。
