# 电赛E题 — 视觉识别与云台控制 通用方法论

## 文档概述

本文档基于2025年电赛E题的三套已验证硬件方案，提炼出**跨硬件平台的通用视觉识别与云台控制方法论**，并提供向 K230 + STM32F407 迁移的完整指南。

**适用场景**：摄像头+激光器安装在移动小车上，检测静止的矩形靶标，控制云台/小车运动使激光对准靶心。

**目标读者**：有嵌入式和AI基础的队友，需手把手级别的可复现指导。

## 一、系统架构全景

### 1.1 通用数据流

```
┌──────────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────┐
│  摄像头  │───→│  视觉处理单元  │───→│  通信接口    │───→│  云台MCU  │
│  (CMOS)  │    │  (目标检测)   │    │  (UART/CAN)  │    │ (PID控制) │
└──────────┘    └──────────────┘    └──────────────┘    └─────┬────┘
                                                              │
                                              ┌───────────────┘
                                              ▼
                                        ┌──────────┐
                                        │ 步进电机  │──→ 云台/小车运动
                                        │ (X轴+Y轴) │
                                        └──────────┘
```

**核心闭环逻辑**（以移动小车+静止靶场景为例）：

1. 摄像头采集 → 检测矩形靶标 → 计算靶心像素坐标
2. 计算靶心与画面中心的**像素偏差** (delta_x, delta_y)
3. 通过UART/CAN将偏差发送给云台MCU
4. MCU执行PID控制 → 输出PWM驱动步进电机 → 云台转动/小车转向
5. 偏差趋近于零 → 对准 → 触发激光

## 二、三套原方案深度解析

### 2.1 方案A：PC + OpenCV（文件夹1）

**文件清单**：
- `recdetect1.py` — 矩形检测v1：HSV黑色掩膜 + Canny + 轮廓筛选
- `recdetect2.py` — 矩形检测v2：同v1，增加上一帧数据回退（检测失败时用历史数据）
- `drawcircle.py` — 透视变换画圆：检测A4纸区域 → 透视矫正 → 生成激光扫描圆轨迹 → 逆映射回原图

**检测算法流程（recdetect1.py/recdetect2.py）**：

```
1. 摄像头采集 (640×480, MJPEG)
2. HSV色彩空间转换 → 黑色掩膜 (V<90)
       ↓ 关键：先做颜色过滤，再转为灰度，大幅减少背景干扰
3. Canny边缘检测 (low=50, high=120)
4. 形态学膨胀 (5×5 kernel, 1~2次迭代)
5. findContours → approxPolyDP (epsilon=0.02*周长)
6. 四边形筛选：
   ├─ 顶点数==4 且 凸多边形
   ├─ 内部区域白色均值 > 100（确保不是全黑背景）
   ├─ 长宽比 1.0~3.0
   └─ 取最大面积
7. 四点排序 (左上→右上→右下→左下)
8. 对角线交点 = 靶心坐标
9. UART发送: [0xAA][0x06][xH][xL][yH][yL][aH][aL][0x55]
```

**recdetect1与recdetect2的关键区别**：
- recdetect2 增加了**历史帧回退机制**：当前帧检测失败时复用上一帧的坐标，避免短暂遮挡导致的控制中断
- recdetect2 的面积最小阈值更高（2000 vs 无限制），过滤掉更多噪点
- recdetect2 使用 `MORPH_CLOSE` 替代 `dilate`，闭运算先膨胀后腐蚀，对填补矩形边框断裂更有效

**drawcircle.py核心思路**（透视变换法画圆）：
```
检测到A4纸4角 → 透视变换矫正为210×297标准矩形
→ 在矫正图上以中心为圆心画R=6cm的圆
→ 圆上N=500个等分采样点
→ 逆透视变换映射回原图 → 得到激光扫描轨迹
→ 每帧输出一个轨迹点坐标
```

### 2.2 方案B：K210 + MSPM0（文件夹2）

**硬件拓扑**：
```
┌──────────────┐     UART2(115200)    ┌──────────────────┐
│  K210/CanMV  │ ──────────────────→  │  MSPM0G350x      │
│  (视觉处理)   │   [+xxxx+yyyy*]      │  (云台PID控制)   │
│  LCD: ST7701 │                      │  OLED: I2C 12864 │
│ 按键: 阈值调节│                      │  IMU: MPU6050    │
└──────────────┘                      │  步进电机: X+Y轴  │
                                      └──────────────────┘
```

**K210端视觉代码 (`8.3.1.py`)**：

使用K210 SDK内置的 `cv_lite.rgb888_find_rectangles_with_corners` 硬件加速函数，直接在RGB888图像上查找矩形及其四个角点坐标。

关键检测参数：
```python
canny_thresh1 = 50        # Canny低阈值
canny_thresh2 = 150       # Canny高阈值
approx_epsilon = 0.04     # 多边形逼近精度
area_min_ratio = 0.001     # 最小面积比例
max_angle_cos = 0.5        # 角度最大余弦值
gaussian_blur_size = 5     # 高斯模糊核大小
```

检测结果验证逻辑（四边形→矩形的筛选）：
```python
1. 面积 > S_THRESHOLD（按键可调，默认2000）
2. 对边长度差 < 120px          # 对边近似相等
3. 四边最小长度 > 30px          # 过滤小噪点
4. 对边平行（角度差 < 30°）      # are_segments_parallel()
5. 邻边垂直（角度差接近90°±30°） # are_segments_vertical()
```

**MSPM0端云台控制**：

接收K210发来的坐标偏差（`x_site`, `y_site`），执行双轴PID控制。

状态机模式：
```
mode=0: 待机
mode=1 + keycnt=3: 主动PID追踪（Kp=0.8, Ki=0, Kd=0）
mode=1 + keycnt=4: 自动对准——偏差<±2(x)/15~20(y)时停止
mode=2 + keycnt=4: X轴正方向扫描（30rpm）
mode=4 + keycnt=4: X轴负方向扫描（-30rpm）
mode=5: 复位
```

PID配置（双轴独立控制）：
```c
// X轴PID（控制水平偏转）
x_stepPid.Kp = 0.084;  // 初始值，运行时通过Pid_Init()覆盖
x_stepPid.Ki = 0.00047;
x_stepPid.Kd = 0;

// Y轴PID（控制俯仰，系数取反）
y_stepPid.Kp = -0.084;
y_stepPid.Ki = -0.00032;
y_stepPid.Kd = 0;
```

步进电机驱动（StepMotor.c）：
- 200步/转 + 16细分 = 3200步/转
- PWM频率直接映射为转速（频率=步数/秒）
- `Calculate_target(rpm)` 将目标转速转为PWM周期值
- `Set_PWM(L,R)` 控制使能、方向和占空比（固定50%）

**CenterGet.py算法详解**（这是三套方案中算法最成熟的版本）：

```python
核心流程：
1. 灰度化 + 高斯模糊(5×5)
2. 二值化阈值处理 (threshold=144)          ← 比Canny更简单直接
3. Canny边缘检测 (low=50, high=150)
4. findContours → approxPolyDP (epsilon=0.01*周长)
5. 四边形多维度评分筛选：
   ├─ 面积 > 500
   ├─ 四边不贴图像边缘（border_threshold=5px）
   ├─ 四个内角都在 70°~110° 范围（接近直角）
   ├─ 对边长度比 <= 5
   ├─ 角度评分(60%权重): 100 - 平均角度偏差
   └─ 面积评分(40%权重): min(100, 面积/最大可能面积*100)
6. 选取综合得分最高的四边形
7. 计算对角交点 → 靶心坐标
```

**通信协议（CarControl.py）**：
```
格式: "deltaX,deltaY,0,0\n"

状态切换：
- send_angle(dx,dy)  → "dx,dy,0,0\n"          正常追踪
- send_speed(L,R)    → "333,333,L,R\n"         速度控制模式
- send_none()        → "404,404,0,0\n"         目标丢失
- send_off()         → "666,666,0,0\n"         关闭电机
```

## 三、视觉识别算法原理

### 3.1 经典CV方法：矩形检测（三套方案的共同核心）

**为什么用矩形检测而不是圆形/HOG/模板匹配？**

电赛E题的靶标是**黑白矩形边框**，具有明确的几何特征：
- 闭合四边形，四个角点清晰
- 内部白色/外部背景可区分
- 对边平行、邻边垂直
- 面积在画面中占比可预测

这些特征使得经典CV方法比YOLO等神经网络更简单、更快、不需训练数据。

**通用算法流程（与硬件平台无关）**：

```
                        ┌──────────┐
                        │ 摄像头帧  │
                        └────┬─────┘
                             ▼
                    ┌───────────────┐
                    │  预处理        │
                    │ (灰度/HSV掩膜) │
                    └───────┬───────┘
                            ▼
                    ┌───────────────┐
                    │  边缘检测      │
                    │ (Canny/Sobel) │
                    └───────┬───────┘
                            ▼
                    ┌───────────────┐
                    │  形态学处理    │
                    │  (膨胀/闭运算) │
                    └───────┬───────┘
                            ▼
                    ┌───────────────┐
                    │  轮廓查找      │
                    │ findContours  │
                    └───────┬───────┘
                            ▼
                    ┌───────────────┐
                    │  多边形逼近    │
                    │ approxPolyDP  │
                    └───────┬───────┘
                            ▼
                    ┌───────────────┐
                    │  四边形筛选    │
                    │  (多维度评分)  │
                    └───────┬───────┘
                            ▼
                    ┌───────────────┐
                    │  对角交点计算  │
                    │  → 靶心坐标    │
                    └───────────────┘
```

**各步骤参数调优指南**：

| 步骤 | 参数 | 效果 | 调参方向 |
|------|------|------|---------|
| HSV掩膜 | V通道上限 | 过滤背景 | 环境暗→降低上限(60-80)；环境亮→提高(90-120) |
| Canny | low_threshold | 边缘敏感度 | 弱边缘→降低(30-50)；噪点多→提高(60-80) |
| Canny | high_threshold | 强边缘阈值 | 一般为low的2-3倍 |
| 膨胀 | kernel大小 | 连接断裂边缘 | 矩形框完整→缩小(3×3)；断裂多→增大(7×7) |
| 膨胀 | iterations | 膨胀次数 | 同上，一次调整一步 |
| approxPolyDP | epsilon比例 | 逼近精度 | 矩形变形大→增大(0.03-0.05)；矩形标准→减小(0.01-0.02) |
| 面积筛选 | min_area | 过滤噪点 | 画面上矩形大→提高；矩形小/远→降低 |

### 3.2 YOLO目标检测方法

当矩形特征不明显（变形、遮挡、光照极端），或需要检测**非矩形目标**时，使用YOLOv8神经网络。

**与经典CV的互补关系**：
| 维度 | 经典CV矩形检测 | YOLOv8 |
|------|:-----------:|:------:|
| 需要训练数据 | 否 | 是（需要标注） |
| 对矩形形变的鲁棒性 | 中（依赖角点清晰） | 高 |
| 对遮挡的鲁棒性 | 低 | 中高 |
| 对光照变化的鲁棒性 | 低 | 高（增强后） |
| 检测非矩形目标 | 不支持 | 支持 |
| 计算资源需求 | 低 | 中高（需NPU加速） |
| 输出信息 | 4角点+中心 | 包围框+类别+置信度 |
| 部署复杂度 | 低 | 中（需模型转换） |

## 四、云台/小车控制原理

### 4.1 双轴PID位置控制（方案B MSPM0实现参考）

```
         x_target=0                   x_stepPid               L_PWM
画面中心 ──────→ [Σ] ──→ [X轴PID] ──→ Calculate_target() ──→ Set_PWM() ──→ X步进电机
                  ↑                                                    │
                  │          UART                                      │
              x_site  ←──────────────←  K230/K210发送的X偏差             │
                  │                                                    ▼
         y_target=18                  y_stepPid               R_PWM   云台偏转
 标定值  ──────→ [Σ] ──→ [Y轴PID] ──→ Calculate_target() ──→ Set_PWM() ──→ Y步进电机
                  ↑
              y_site  ←──────────────←  K230/K210发送的Y偏差
```

**PID参数物理含义**：

| 参数 | 作用 | 典型范围 | 过大导致 | 过小导致 |
|------|------|---------|---------|---------|
| Kp | 比例增益——响应速度 | 0.05~1.0 | 超调振荡 | 响应慢、静态误差大 |
| Ki | 积分增益——消除稳态误差 | 0.0001~0.01 | 积分饱和、过冲 | 有静态误差时无法对准 |
| Kd | 微分增益——抑制超调 | 0~0.1 | 对噪声敏感、抖动 | 超调无法抑制 |

**方案B的调参经验**（来自实测）：
```
精细对准模式: Kp=0.084, Ki=0.00047, Kd=0        ← 稳定但响应慢
快速跟踪模式: Kp=0.8,   Ki=0,       Kd=0        ← 响应快但可能有超调
Y轴系数取反:  y_stepPid.Kp = -x_stepPid.Kp      ← 因为Y轴电机安装方向相反
```

### 4.2 步进电机驱动

**PWM频率→转速映射**（方案B实现）：
```
步进电机参数: 200步/转 × 16细分 = 3200步/转
PWM时钟: 10MHz
PWM周期 = (10,000,000 / 目标频率) - 1
目标频率 = (转速rpm × 3200) / 60 = 转速 × 53.33 Hz

示例: 转速30rpm → 频率=1600Hz → PWM周期=6249
      转速60rpm → 频率=3200Hz → PWM周期=3124
      转速 0rpm → PWM=0 (禁用输出)
```

**方向控制**：
- EN引脚 = HIGH → 使能电机（保持力矩）
- DIR引脚: HIGH=正转, LOW=反转
- PWM占空比固定50%

### 4.3 状态机设计（多模式切换）

参考方案B的 `mode` + `keycnt` 组合状态机：
```
mode=0: IDLE        — 待机，电机不使能
mode=1: TRACK       — PID追踪，keycnt=3或4切换子模式
mode=2: SCAN_RIGHT  — 单向扫描，检测到目标后切回TRACK
mode=4: SCAN_LEFT   — 反向扫描
mode=5: RESET       — 复位到TRACK
```

## 五、通信协议规范

### 5.1 三套方案协议对比

| 方案 | 帧格式 | 示例 | 优点 | 缺点 |
|------|--------|------|------|------|
| A | `0xAA + len + xH+xL + yH+yL + aH+aL + 0x55` | `AA 06 00 F0 01 2C 00 05 55` | 二进制高效 | 调试不便 |
| B | `[+xxxx+yyyy*]` | `[-0110+0045*]` | 可读性好 | 定长限制 |
| C | `deltaX,deltaY,0,0\n` | `-25,18,0,0\n` | 扩展性好 | 解析开销 |

### 5.2 K230 + STM32F407 推荐协议

**默认方案：文本CSV（向后兼容方案C的STM32F407协议）**
```
格式: "deltaX,deltaY,velocityX,velocityY\n"
- deltaX/deltaY: 像素偏差（int, 可为负值）, 正规跟踪模式
- 特殊标识: "333,333,L,R\n"   速度控制模式（L/R为左右轮速度）
- 特殊标识: "404,404,0,0\n"   目标丢失通知
- 特殊标识: "666,666,0,0\n"   停止电机
```

**可选方案：二进制帧（高效模式）**
```
帧格式: [0xAA][0x08][xH][xL][yH][yL][mode][conf][crc16][0x55]
- x, y: 16位有符号像素偏差
- mode: 检测模式(0=classical, 1=yolo, 2=hybrid)
- conf: 置信度/质量评分(0-100)
- crc16: CRC16校验
```

### 5.3 CAN总线可选配置

CAN总线适合电磁干扰大的环境或需要多节点通信的场景：
```
CAN参数:
- 波特率: 500kbps（推荐）/ 1Mbps
- 帧格式: 标准帧(CAN 2.0A, 11位ID)
- 数据长度: 8字节（单帧可容纳所有偏差数据）
- STM32F407: CAN1已初始化（见CubeMX配置）
- K230侧: 需外接MCP2551/MCP2562 CAN收发器
```

```python
# detectors/classical.py
import cv2
import numpy as np

class ClassicalDetector:
    def __init__(self, config):
        self.canny_low = config['classical']['canny_low']
        self.canny_high = config['classical']['canny_high']
        self.area_min = config['classical']['area_min']
        self.approx_epsilon = config['classical']['approx_epsilon']
        self.aspect_ratio_min = config['classical']['aspect_ratio_min']
        self.aspect_ratio_max = config['classical']['aspect_ratio_max']
        self.use_hsv_mask = config['classical']['use_hsv_mask']
        self.hsv_v_max = config['classical']['hsv_v_max']
        self.morph_kernel = config['classical']['morph_kernel']
        self.morph_iter = config['classical']['morph_iterations']
        
        self.last_center = None
        self.last_corners = None

    def detect(self, frame):
        """
        Returns: {
            'center': (cx, cy),
            'corners': [(x0,y0),(x1,y1),(x2,y2),(x3,y3)],
            'confidence': 0-100,
            'method': 'classical'
        } or None
        """
        if self.use_hsv_mask:
            hsv = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)
            mask = cv2.inRange(hsv, np.array([0,0,0]), np.array([180,255,self.hsv_v_max]))
            gray = mask  # 直接使用掩膜作为灰度图
        else:
            gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)

        blurred = cv2.GaussianBlur(gray, (5, 5), 0)
        edges = cv2.Canny(blurred, self.canny_low, self.canny_high)
        
        kernel = cv2.getStructuringElement(cv2.MORPH_RECT, 
                                           (self.morph_kernel, self.morph_kernel))
        dilated = cv2.dilate(edges, kernel, iterations=self.morph_iter)
        
        contours, _ = cv2.findContours(dilated, cv2.RETR_EXTERNAL, 
                                        cv2.CHAIN_APPROX_SIMPLE)
        
        best = None
        best_score = -1
        best_center = None
        best_corners = None
        
        h, w = frame.shape[:2]
        
        for cnt in contours:
            area = cv2.contourArea(cnt)
            if area < self.area_min:
                continue
            
            peri = cv2.arcLength(cnt, True)
            approx = cv2.approxPolyDP(cnt, self.approx_epsilon * peri, True)
            
            if len(approx) != 4 or not cv2.isContourConvex(approx):
                continue
            
            pts = approx.reshape(4, 2)
            
            # 排序: 左上→右上→右下→左下
            rect = np.zeros((4, 2), dtype=np.float32)
            s = pts.sum(axis=1)
            rect[0] = pts[np.argmin(s)]  # 左上
            rect[2] = pts[np.argmax(s)]  # 右下
            diff = np.diff(pts, axis=1)
            rect[1] = pts[np.argmin(diff)]  # 右上
            rect[3] = pts[np.argmax(diff)]  # 左下
            
            # 长宽比检查
            bw = np.linalg.norm(rect[1] - rect[0])
            bh = np.linalg.norm(rect[3] - rect[0])
            if bw == 0 or bh == 0:
                continue
            ratio = max(bw, bh) / min(bw, bh)
            if ratio < self.aspect_ratio_min or ratio > self.aspect_ratio_max:
                continue
            
            # 对角交点
            center = self._line_intersection(rect[0], rect[2], rect[1], rect[3])
            if center is None:
                continue
            
            # 评分
            area_score = min(100, area / (w * h / 8) * 100)
            rect_score = min(100, 100 - abs(1 - ratio) * 50)
            score = 0.6 * rect_score + 0.4 * area_score
            
            if score > best_score:
                best_score = score
                best_center = (int(center[0]), int(center[1]))
                best_corners = rect.astype(int).tolist()
        
        if best_center is not None:
            self.last_center = best_center
            self.last_corners = best_corners
            return {
                'center': best_center,
                'corners': best_corners,
                'confidence': best_score,
                'method': 'classical'
            }
        
        # 回退到上一帧
        if self.last_center is not None:
            return {
                'center': self.last_center,
                'corners': self.last_corners,
                'confidence': 30,  # 低置信度
                'method': 'classical'
            }
        return None

    def _line_intersection(self, p1, p2, p3, p4):
        A = np.array([[p2[0]-p1[0], p3[0]-p4[0]],
                      [p2[1]-p1[1], p3[1]-p4[1]]], dtype=float)
        b = np.array([p3[0]-p1[0], p3[1]-p1[1]], dtype=float)
        try:
            t = np.linalg.solve(A, b)
            return p1 + t[0] * (p2 - p1)
        except np.linalg.LinAlgError:
            return None
```

import serial

import yaml

class Transport:
    def __init__(self, config):
        comm = config['communication']
        self.protocol = comm['protocol']  # 'uart' / 'can'
        self.format = comm['format']      # 'csv' / 'binary'
        
        if self.protocol == 'uart':
            self.ser = serial.Serial(
                port=comm['uart']['port'],
                baudrate=comm['uart']['baud'],
                timeout=0.1
            )
        elif self.protocol == 'can':
            # CAN初始化（需额外硬件）
            pass

    def send_delta(self, dx, dy, mode='track'):
        """发送偏差到云台MCU"""
        if self.format == 'csv':
            if mode == 'track':
                data = f"{dx},{dy},0,0\n"
            elif mode == 'lost':
                data = "404,404,0,0\n"
            elif mode == 'stop':
                data = "666,666,0,0\n"
            elif mode == 'speed':
                data = f"333,333,{dx},{dy}\n"
            self.ser.write(data.encode('utf-8'))
        
        elif self.format == 'binary':
            # 二进制帧格式
            frame = bytearray([0xAA, 0x08])
            frame.extend(struct.pack('>hh', dx, dy))
            frame.extend([0x00, 0x00, 0x00, 0x00])  # mode, conf, crc placeholder
            frame.append(0x55)
            self.ser.write(frame)

    def close(self):
        if hasattr(self, 'ser'):
            self.ser.close()

```python
# main.py
import cv2
import yaml
import time
from detectors.classical import ClassicalDetector
from detectors.yolo import YOLODetector
from communication.transport import Transport
from utils.kalman import KalmanFilter2D

def load_config(path='config.yaml'):
    with open(path, 'r') as f:
        return yaml.safe_load(f)

def main():
    config = load_config()
    
    # 初始化检测器
    mode = config['detection']['mode']
    if mode in ('classical', 'hybrid'):
        classical_det = ClassicalDetector(config)
    if mode in ('yolo', 'hybrid'):
        yolo_det = YOLODetector(config)
    
    # 初始化通信
    transport = Transport(config)
    
    # 初始化摄像头 (K230)
    cap = cv2.VideoCapture(config['camera']['device'])
    cap.set(cv2.CAP_PROP_FRAME_WIDTH, config['camera']['width'])
    cap.set(cv2.CAP_PROP_FRAME_HEIGHT, config['camera']['height'])
    cap.set(cv2.CAP_PROP_FPS, config['camera']['fps'])
    
    # 画面中心
    cx_center = config['camera']['width'] // 2
    cy_center = config['camera']['height'] // 2
    
    # 卡尔曼滤波器
    kf = KalmanFilter2D(npoints=1, dt=config['kalman']['dt'])
    
    print(f"Detection mode: {mode}")
    print(f"Camera: {config['camera']['width']}x{config['camera']['height']}")
    print(f"Comm: {config['communication']['protocol']} / {config['communication']['format']}")
    
    try:
        while True:
            ret, frame = cap.read()
            if not ret:
                continue
            
            result = None
            
            if mode == 'classical':
                result = classical_det.detect(frame)
            elif mode == 'yolo':
                result = yolo_det.detect(frame)
            elif mode == 'hybrid':
                # 两路并行，取置信度高的
                r1 = classical_det.detect(frame)
                r2 = yolo_det.detect(frame)
                if r1 and r2:
                    result = r1 if r1['confidence'] > r2['confidence'] else r2
                else:
                    result = r1 or r2
            
            if result and result['center'] is not None:
                cx, cy = result['center']
                delta_x = cx_center - cx
                delta_y = cy_center - cy
                
                # 卡尔曼滤波平滑
                filtered = kf.predict(np.array([[delta_x, delta_y]]))
                dx, dy = int(filtered[0][0]), int(filtered[0][1])
                
                transport.send_delta(dx, dy, mode='track')
                print(f"[{result['method']}] dx={dx:+4d} dy={dy:+4d} conf={result['confidence']:.0f}")
            else:
                transport.send_delta(0, 0, mode='lost')
    
    except KeyboardInterrupt:
        print("\nStopped.")
    finally:
        cap.release()
        transport.close()

if __name__ == '__main__':
    main()
```

## 七、双模式检测架构设计

### 7.1 模式定义

| 模式 | config值 | 加载的检测器 | 适用场景 |
|------|----------|-----------|---------|
| 纯经典CV | `classical` | ClassicalDetector | 矩形靶标、光照可控、追求低延迟 |
| 纯YOLO | `yolo` | YOLODetector | 非矩形目标、复杂背景、需要类别区分 |
| 混合模式 | `hybrid` | 两者并行→仲裁 | 现场不确定、需要最高鲁棒性 |

### 7.2 混合模式仲裁策略

```
输入帧
  │
  ├──→ ClassicalDetector.detect() ──→ {confidence: score_c, ...}
  │
  └──→ YOLODetector.detect()      ──→ {confidence: score_y, ...}
                                          │
                                          ▼
                              ┌─────────────────────┐
                              │  仲裁器             │
                              │ if score_c > score_y│
                              │    → classical结果  │
                              │  else               │
                              │    → yolo结果       │
                              │  (两者都None→lost)  │
                              └─────────────────────┘
```

### 7.3 置信度归一化

两种检测器的置信度需要归一化到0-100以便比较：
- ClassicalDetector: 四边角度评分(60%) + 面积评分(40%)，天然在0-100范围
- YOLODetector: YOLO输出的objectness confidence ∈ [0,1]，乘以100即归一化

```
1. 搭建与比赛相同的场地环境（光照、背景、距离）
2. 小车上电，摄像头对准靶标区域
3. 录制视频（≥5分钟），覆盖：
   ├─ 不同距离（1m/2m/3m/5m）
   ├─ 不同角度（正面/±15°/±30°/±45°）
   ├─ 不同光照（开灯/关灯/半光/自然光）
   ├─ 部分遮挡（模拟比赛中的遮挡场景）
   └─ 不同背景（场地不同区域）
4. 从视频中每10帧抽取1帧作为图片
5. 去重（删除高度相似的连续帧）
6. 人工检查并剔除模糊/过曝/全黑的图片
7. 按8:2随机划分为train/val
8. 用标注工具逐张标注
```

### 10.3 训练脚本

见配套文档 `02_训练配置指南.md`。

### 10.4 量化数据集

从训练集中挑选100-200张**最具代表性**的图片（覆盖所有场景变化），放入 `quant_dataset/` 目录，用于模型量化校准。

## 十一、现场部署检查清单

### 11.1 赛前准备

- [ ] 确认config.yaml中`detection.mode`设置正确
- [ ] 确认摄像头分辨率与画面中心点匹配
- [ ] 确认UART波特率与云台MCU一致
- [ ] 确认步进电机方向——发送正偏差时电机应向减小偏差方向转动
- [ ] 确认激光器GPIO引脚和触发逻辑
- [ ] 在比赛场地同样光照下测试10次，统计对准成功率
- [ ] 准备备用SD卡（预烧录系统+模型）

### 11.2 赛中应急预案

| 问题 | 快速解决 |
|------|---------|
| 检测不到 | 切换模式：`yolo` → `classical` 或反之 |
| 检测到但不准 | 调低NMS/提高confidence |
| 通信中断 | 检查接线 → 切换通信格式 → 重启 |
| 云台乱转 | 拔掉电机使能 → 检查PID参数 → 重启MCU |
| 全程误检 | 切换HSV掩膜开关 `use_hsv_mask: true/false` |
