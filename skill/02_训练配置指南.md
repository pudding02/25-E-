### 2.3 YOLO标注格式

每张图片对应一个同名`.txt`文件，每行一个目标：

```
<class_id> <x_center> <y_center> <width> <height>
```

- 所有坐标均为**归一化值（0-1）**，相对于图片宽高
- `x_center = (box_left + box_right) / 2 / image_width`
- `y_center = (box_top + box_bottom) / 2 / image_height`
- `width = (box_right - box_left) / image_width`
- `height = (box_bottom - box_top) / image_height`

**示例**（图片640×480，矩形框左上角(120,100) 右下角(520,380)）：
```
0 0.5 0.5 0.625 0.583
```

### 2.4 标注工具推荐

| 工具 | 平台 | 优点 | 下载 |
|------|------|------|------|
| LabelImg | Win/Mac/Linux | 轻量，YOLO格式原生支持 | `pip install labelImg` |
| Roboflow | Web | 在线协作，自动增强，格式导出 | roboflow.com |
| CVAT | Web/Docker | 专业级，支持团队协作 | cvat.ai |

### 2.5 标注规范

1. **标注目标**：矩形靶标的**外边框**，紧密贴合四个角点
2. **遮挡处理**：如果靶标被部分遮挡，标注**可见部分的外边框**（不要猜测被遮挡部分）
3. **边界处理**：如果靶标部分超出画面，标注**画面内的可见部分**
4. **质量检查**：每张标注完后放大检查，确保框紧贴边缘、无偏移
5. **交叉验证**：建议每人标注完后交换检查，发现偏差>5px的重新标注

### 2.6 数据采集建议

**采集场景覆盖矩阵**（每格≥20张）：

| | 正面(0°) | 左偏15° | 右偏15° | 左偏30° | 右偏30° | 左偏45° | 右偏45° |
|------|:--:|:--:|:--:|:--:|:--:|:--:|:--:|
| 1m | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| 2m | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| 3m | ✓ | ✓ | ✓ | ✓ | ✓ | - | - |
| 5m | ✓ | ✓ | ✓ | - | - | - | - |

**光照变化**（每个距离×角度组合至少1张）：
- 正常室内灯光
- 关灯/暗光
- 侧面打光（模拟窗户）
- 靶标反光（如果有）

**负样本**（训练集中不需要，但采集时建议同时拍一些无靶标的场景用于测试误检率）

## 三、训练脚本

### 3.1 基础训练脚本 (`train.py`)

```python
"""
电赛E题 — YOLOv8目标检测训练脚本
使用方法: python train.py
修改下方 CONFIG 区域即可适配不同场景
"""
from ultralytics import YOLO
import os

# ==================== 配置区（根据实际情况修改） ====================
CONFIG = {
    # 数据集配置文件路径
    'data': 'dataset/data.yaml',

    # 预训练模型 — yolov8n最轻量适合K230
    # 可选: yolov8n.pt / yolov8s.pt / yolov8m.pt / yolov8l.pt
    'model': 'yolov8n.pt',

    # ★ 输入尺寸 — 必须与K230部署尺寸一致！
    # 320: K230最佳（16/32对齐）推荐
    # 224: 更快但精度略低
    # 416: 精度更高但K230帧率下降
    'imgsz': 320,

    # ★ 训练轮数 — 一般100-200轮
    # 数据少→多训练（200+）；数据多→可少训（100）
    'epochs': 200,

    # ★ 批次大小 — 根据GPU显存调整
    # 4GB显存: batch=8；8GB: batch=16；16GB+: batch=32
    'batch': 16,

    # 设备: 0=GPU, 'cpu'=CPU
    'device': 0,

    # 数据加载进程数
    'workers': 4,

    # 预训练权重 — 强烈建议True
    'pretrained': True,

    # ★ 优化器: SGD(推荐) / Adam / AdamW
    # SGD: 收敛慢但泛化好；Adam: 收敛快
    'optimizer': 'SGD',

    # ★ 初始学习率
    # SGD: 0.01；Adam: 0.001
    'lr0': 0.01,

    # 余弦学习率衰减 — 推荐True
    'cos_lr': True,

    # ★ 早停耐心值 — 验证集loss连续不降则提前停止
    # 50表示连续50轮无改善则停止
    'patience': 50,

    # 缓存图片到内存加速训练（小数据集推荐True）
    'cache': True,

    # ★ Mosaic增强 — 最后N轮关闭（提高最终精度）
    'close_mosaic': 10,

    # 输出目录
    'project': './runs/detect',
    'name': 'e_target_detect',

    # 生成可视化图表
    'plots': True,

    # 保存每个epoch的检查点（会占用大量磁盘）
    'save': True,
}
# ==================================================================


def main():
    print("=" * 60)
    print("YOLOv8 训练开始")
    print(f"模型: {CONFIG['model']}")
    print(f"数据: {CONFIG['data']}")
    print(f"尺寸: {CONFIG['imgsz']}x{CONFIG['imgsz']}")
    print(f"轮数: {CONFIG['epochs']}, 批次: {CONFIG['batch']}")
    print("=" * 60)

    # 检查数据集配置文件是否存在
    if not os.path.exists(CONFIG['data']):
        print(f"错误: 找不到数据集配置文件 {CONFIG['data']}")
        return

    # 加载模型
    model = YOLO(CONFIG['model'])

    # 开始训练
    results = model.train(
        data=CONFIG['data'],
        epochs=CONFIG['epochs'],
        imgsz=CONFIG['imgsz'],
        batch=CONFIG['batch'],
        device=CONFIG['device'],
        workers=CONFIG['workers'],
        pretrained=CONFIG['pretrained'],
        optimizer=CONFIG['optimizer'],
        lr0=CONFIG['lr0'],
        cos_lr=CONFIG['cos_lr'],
        patience=CONFIG['patience'],
        cache=CONFIG['cache'],
        close_mosaic=CONFIG['close_mosaic'],
        project=CONFIG['project'],
        name=CONFIG['name'],
        plots=CONFIG['plots'],
        save=CONFIG['save'],
    )

    # 导出ONNX（用于后续KModel转换）
    print("\n导出ONNX...")
    model.export(
        format='onnx',
        opset=11,           # K230要求opset 11
        simplify=True,      # 简化模型图
        imgsz=CONFIG['imgsz'],
    )

    print(f"\n训练完成！")
    print(f"模型输出: {CONFIG['project']}/{CONFIG['name']}/weights/best.pt")
    print(f"ONNX输出: {CONFIG['project']}/{CONFIG['name']}/weights/best.onnx")


if __name__ == '__main__':
    main()
```

### 3.3 数据增强策略

YOLOv8内置增强（训练时自动应用，无需额外配置）：
- **Mosaic**: 4张图拼接为1张（默认开启，最后10轮关闭）
- **MixUp**: 2张图按比例混合
- **HSV色彩抖动**: 色调/饱和度/亮度随机变化（模拟光照变化）
- **随机翻转**: 水平翻转（默认开启）
- **缩放/平移**: 随机缩放和平移

针对电赛场景的**额外增强建议**：
```python
# 在训练脚本中加入自定义增强参数
model.train(
    ...
    # 针对电赛场景的增强
    hsv_h=0.015,      # 色调变化范围（小——靶标颜色固定）
    hsv_s=0.3,        # 饱和度变化（中）
    hsv_v=0.3,        # ★ 亮度变化（大——模拟不同光照）
    degrees=15.0,     # ★ 旋转角度（大——小车视角变化）
    translate=0.1,    # 平移比例
    scale=0.3,        # ★ 缩放比例（大——模拟不同距离）
    shear=2.0,        # 剪切角度
    flipud=0.0,       # 垂直翻转概率（0=不翻转——靶标不会倒挂）
    fliplr=0.5,       # 水平翻转概率
)
```

### 3.4 难例挖掘策略

如果训练后的模型在特定场景下表现差：

```
1. 收集模型"犯错"的图片（漏检/误检/框不准）
2. 将这些图片加入训练集
3. 重新训练（可降低lr0=0.001微调）
4. 重复直到满意
```

这比盲目增加训练数据量更高效。

> 详细步骤参考 `K230-DRONE-AI-SKILL.md` 第五节。这里仅总结关键配置。

### 5.1 量化数据集准备

从训练集/验证集中挑选100-200张图片，要求：
- 覆盖所有距离、角度、光照条件

- 放入 `quant_dataset/` 目录

### 5.2 转换关键配置（速查）

| 配置项 | 正确值 | ★重要性 | 错误后果 |
|--------|--------|:-----:|---------|
| NNCase版本 | 2.8.3 | ★★★ | KPU运行失败 |
| Python版本 | 3.10 | ★★★ | NNCase不兼容 |
| opset | 11 | ★★★ | 模型无法导入 |
| `preprocess` | True | ★★★ | 检测框乱飘 |
| `input_type` | "uint8" | ★★★ | 检测框乱飘 |
| `calibrate_method` | "NoClip" | ★★ | 框不准（Kld也可能可用的） |
| 校准数据格式 | uint8 (0-255) | ★★★ | 框乱飘 |
| `input_shape` | [1,3,320,320] | ★★ | 尺寸不匹配 |

## 六、训练效果不佳的排查

| 问题 | 可能原因 | 解决 |
|------|---------|------|
| loss不收敛 | 学习率太高 | 降低lr0→0.001 |
| | 标注错误多 | 抽查10%标注，修正错误 |
| | 数据太少 | 增加训练数据 |
| 训练集精度高/验证集差 | 过拟合 | 增加数据增强强度；增加dropout |
| | 数据集太少 | 增加数据量 |
| | 训练/验证集分布不同 | 重新随机划分数据集 |
| 小目标漏检 | 目标在画面中太小 | 提高imgsz: 320→416→640 |
| 特定角度漏检 | 该角度训练数据不足 | 补充该角度的数据 |
| 特定光照漏检 | 光照数据不足 | 补充光照变化数据 + 加强HSV增强 |
| 假阳性太多 | 负样本不够 | 添加无目标背景图到训练集 |
